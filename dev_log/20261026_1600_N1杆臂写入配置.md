## 1. 背景

用户要求把 `neptune-sim` 里 `N1_robot/model.sdf` 的 fog 到后轮中心、以及后轮中心到各里程计的相对杆臂写入本工程配置。尚未接入融合。

## 2. 讨论脉络

`FogImuPublisherSystem` 的 `source_link` 是 `n1_chassis`，测量点在底盘原点。左右驱动轮为 `(0, 0, ±0.4235)`，中点即后轮中心，与 fog 重合，所以 fog→后轮中心为 0。底盘轴为前 x、上 y、右 z。各轮心相对该原点：

| 轮 | SDF 来源 | x y z (m) |
| --- | --- | --- |
| 大轮右 | `right_wheel` | 0, 0, 0.4235 |
| 大轮左 | `left_wheel` | 0, 0, -0.4235 |
| 大轮前 | `turning_frame` | 0.68, 0, 0 |
| 小轮右 | `right_caster_slider` | 0, -0.075, 0.24 |
| 小轮左 | `left_caster_slider` | 0, -0.075, -0.24 |

写入 `config/localization_v2.yaml`，节点里声明同名 `vector<double>`，否则参数文件里的新键加载不进去。`./build.py -b naiad_localization_v2` 于 16:00 成功。

## 3. 结论

- 杆臂在 `localization_v2.yaml`，坐标系与 SDF 底盘一致（前、上、右），单位米。
- fog 到后轮中心是 `[0, 0, 0]`。
- 融合还没用这些杆臂。正在跑的节点要重新 launch。
