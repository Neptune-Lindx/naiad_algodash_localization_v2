## 1. 背景

五个轮速已经是 m/s。用户要求用 fog 姿态、角速度和配置杆臂，把各轮速折到 fog，新建结构体保存并实时打印，原来的轮速打印保留。

## 2. 讨论脉络

杆臂和陀螺都在 fog 机体：前 x、上 y、右 z。各轮滚动方向按 fog 前向，轮心速度取 `(v, 0, 0)`。fog 到该轮的杆臂是 `lever_fog_to_rear_center + lever_rear_to_*`。

`v_fog = (v, 0, 0) - ω × l`，结果在 `WheelSpeedAtFog` 的 `*_body`。再用 fog 四元数（机体到北天东）得到 `*_nte`，分量是北、天、东。

没有 fog 时只打原来的轮速。`./build.py -b naiad_localization_v2` 于 16:13 成功。

## 3. 结论

- 结构体 `WheelSpeedAtFog`，节点成员 `wheel_speed_at_fog_`。
- 控制台在原轮速行后多两行：`fog body` 和 `fog nte`。
- 前轮和万向轮的滚动方向暂按车体前向，没有转向角。融合还没使用这组速度。
