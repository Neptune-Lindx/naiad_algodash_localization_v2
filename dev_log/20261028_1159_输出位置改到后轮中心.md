## 1. 背景

对外右前上的大船位置和全局经纬高原先是 IMU 点。用户要求这两处都落到后轮中心。

## 2. 讨论脉络

积分、轮速和 NHC 仍在 IMU。杆臂用配置 `lever_fog_to_rear_center`，轴是前上右，换成前右下后加到船体系和 ECEF。设位的 position 和固定锚点经纬高按后轮中心解释，所以设 0 时后轮中心在原点、经纬高在锚点。

## 3. 结论

- $p_{\mathrm{rear}}^s = p_{\mathrm{imu}}^s + C_b^s l^b$，$r_{\mathrm{rear}}^e = r_{\mathrm{imu}}^e + C_b^e l^b$。
- 右前上输出和 `fusion ship p` 用 $p_{\mathrm{rear}}^s$。经纬高用 $r_{\mathrm{rear}}^e$。
- 线速度加上 $\omega^b\times l^b$，与后轮中心位置一致。
- N1 配置里该杆臂是 `[0,0,0]`，FOG 与后轮中心重合，数值上不会挪开。
