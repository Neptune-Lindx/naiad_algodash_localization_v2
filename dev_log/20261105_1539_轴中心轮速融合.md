## 1. 背景

轮速融合原来是每个轮子各自杆臂补偿后再进 5 行观测。按书上轴中心模型，同一根轴左右轮应先平均，再用轴中心杆臂补到 IMU，只融合补完的前向速度。前轮仍不融合。NHC 本轮不改，仍是每个 IMU 步。

## 2. 讨论脉络

N1 后轮轴中心与 FOG 重合，左右大轮平均后杆臂为 0。小轮中点前-上-右是 `(0, -0.075, 0)`，前-右-下是 `(0, 0, 0.075)`，转弯时 `ω × l` 的前向分量不抵消。小轮没有转向角，与后轮一样用 `C = I`。

状态保持 20 维。观测向量仍是 5 行、2 Hz、`R = (0.1 m/s)^2`。只有第 0 行（大轮，比例因子 `s_0`、`s_1`）和第 3 行（小轮，`s_3`、`s_4`）有新息。增益是 `1 + (s_a + s_b) / 2`，比例因子列各写 `v_x / 2`，不再乘增益。

## 3. 结论

- 大轮、小轮各自先平均，再按该对中点杆臂做 `v = (v, 0, 0) - ω × l`。结果放在 `motor_right` 和 `small_right` 的前向分量。
- 左轮、前轮、小轮另一行的 `H` 和新息为 0。前轮比例因子仍无观测。
