## 1. 背景

`test_odo` 在侧板的轨迹是对的。机器人走到底板后，积分位置往大船右-前-上的 x 反方向走。只改 `tools/test_odo.cpp`。

## 2. 讨论脉络

原来用 `fog/data` 的 roll、pitch、yaw 减 AIS 船首向，再按 3-2-1 转成方向余弦。侧板横滚约 +90°、航向接近 0 时，这组和四元数一致，前向速度留在大船前向。

底板相当于机体翻过去，横滚约 180°。厂商欧拉航向和真实航向反号。船体系航向 +90°（车头指向大船右）时，欧拉给出 -90°，右-前-上的速度从 (+v, 0, 0) 变成 (-v, 0, 0)。纯横滚、纵摇为 0、相对航向为 0 时两边仍都是正前，所以只在底板上转弯才看出来。

四元数是前-上-右到北-天-东。前向取第一列，再换成北东地，用 AIS 船首向（从北向东为正）转到大船前-右-下。侧板、底板、船首向非零都和几何真值一致。

## 3. 结论

`test_odo` 不再用 roll、pitch、yaw。速度由 `orientation` 和 AIS 船首向积分。发布的欧拉角、四元数、方向余弦也改成这套大船系姿态。10:50 编译通过。需要重新 `ros2 run naiad_localization_v2 test_odo`。
