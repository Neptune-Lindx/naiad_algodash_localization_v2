# 仿真启动脚本

2026-11-16 18:54

按 `naiad_algodash_localization_sim` 的三终端流程，在本包加了启动脚本，不改兄弟包。

- `scripts/start_neptune_sim_localization_v2.sh`：start / status / stop。读源文件 `config/localization_v2.yaml` 起节点，读 `config/neptune_sim.yaml` 补话题并设位。
- 跳过 FOG 对准：发布 `fog/state=ALIGNMENT_DONE`。v2 的 `algo/set_position` 本身不看这个状态，只要求已经有 `fog/data`。
- 位置初值：`initial_x/y/z`，大船右-前-上，默认 0。没有 `algo/transform`。
- 成功标志：`/localization_v2/odometry` 出一帧。姿态在 `/localization_v2/status` 的 `rpy_s`、`rpy_n`。
- 操作说明：`man/localization_v2_sim.md`。不要和旧 `naiad_localization` 同时跑，服务名都是 `algo/set_position`。
