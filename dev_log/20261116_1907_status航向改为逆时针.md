# status 航向改为逆时针

> 保存时间：2026-11-16 19:07 (UTC+8)
> 工作区：naiad_algodash_localization_v2
> 触发方式：主动收尾

## 1. 背景

`/localization_v2/status` 的 `rpy_s`、`rpy_n` 航向来自 `cbn_to_rpy`，坐标系分别是前-右-下和北-东-地，z 朝下。

## 2. 讨论脉络

用户确认若是顺时针递增，只在 status 打印时改成逆时针，滤波内部坐标系不动。

## 3. 结论

- 原来是绕朝下的 z 轴、从上往下看顺时针为正。右转到 +90°，左转到 −90°。
- `node_localization_v2.cpp` 的 status 字符串里，`rpy_s` 和 `rpy_n` 的航向打印为 `-yaw`，并折回 (−180, 180]。横滚、俯仰不改。
- 里程计 `pose.euler.yaw`、四元数、方向余弦和滤波状态仍是内部顺时针航向。
- 已编译通过。正在跑的节点要重新启动才看得到。
