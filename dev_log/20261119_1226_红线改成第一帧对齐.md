## 1. 背景

把设位改成当前 `rel_odo` 之后，Gazebo 里的线还是接不到机器人。旧仿真定位 `naiad_algodash_localization_sim` 的蓝线能接上。

## 2. 讨论脉络

红线原来的 `truth_start_offset` 是「黑线第一个点减红线第一帧」，第一帧永远画在黑线起点上。机器人已经离开起点时，线头留在旧原点，线尾比机器人短一截。设位数字改成多少都会被这个减法消掉。

旧蓝线是 `first_frame_ship_aligned`：`p_S(k) = 锁定时的船体系位置 + 之后的位移`。停超过 5 秒会清线并按当前机器人重新锁。设位本身仍是 `0 0 0`，`frame_id` 为 `odom`。

## 3. 结论

- v2 的红线和绿线改成和旧蓝线同一种锁定。设位恢复成 yaml 里的 `0 0 0`。
- 世界文件要重新加载。先关 Gazebo 再开，然后停掉定位脚本再启动。
